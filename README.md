# Glyphora Flutter Dictionary

Flutter dictionary client for multiple language datasets.

The app supports two SQLite layouts:

1. **Legacy table dictionaries** used by the existing Russian and Vietnamese assets.
2. **Canonical lexical databases** generated by the language engines, beginning with the Kyrgyz morphology dictionary.

## Canonical Kyrgyz integration

The Kyrgyz generator produces a normalized SQLite database with:

```text
lexemes
├── senses
│   └── glosses
├── noun_forms
└── verb_forms
```

The Flutter app detects that schema automatically and uses it without converting it back to the older `*_table` format.

Supported canonical search paths:

```text
алуу       → lemma
алдым      → inflected form → алуу
buy        → gloss → алуу
买          → gloss → алуу
покупать   → gloss → алуу
```

Search priority is:

```text
lemma > form > gloss
```

When a real inflected form is matched, the result keeps all grammatical analyses and structured morphology features.

## Importing the Kyrgyz database

Generate the canonical database in `kyrgyz-inflection-generator`, then copy it into this project as:

```text
assets/databases/ky.db
```

The asset directory is already included by `pubspec.yaml`.

The Flutter data layer will automatically distinguish `ky.db` from the legacy `ru.db` and `vi.db` files.

## Development

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

`glyphora_language_core` is pulled from the `flutter-languages-config` GitHub repository, so the project no longer depends on a machine-specific local Windows path.
